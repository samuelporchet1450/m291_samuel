## À retenir
- **Repo** = dossier versionné. **Commit** = photo datée d'un changement. **Push** = envoyer ses commits sur GitHub. **Clone** = copie locale d'un repo distant.
- `index.html` **à la racine** sinon GitHub Pages n'affiche rien.
- Repo **public** obligatoire pour Pages gratuit.
